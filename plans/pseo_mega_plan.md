### Database Functions

```sql
-- Get next batch of highest-priority pending items
CREATE OR REPLACE FUNCTION pseo.get_next_batch(p_limit INTEGER DEFAULT 20)
RETURNS TABLE (
  queue_id INTEGER,
  location_slug TEXT,
  location_name_ar TEXT,
  location_name_en TEXT,
  country_code TEXT,
  country_ar TEXT,
  region_ar TEXT,
  climate TEXT,
  villa_count_estimate INTEGER,
  permit_authority TEXT,
  pillar_slug TEXT,
  pillar_name_ar TEXT,
  intent TEXT,
  format TEXT,
  target_keyword_ar TEXT,
  priority_score DECIMAL
) AS $$
BEGIN
  RETURN QUERY
  SELECT 
    cq.id AS queue_id,
    l.slug AS location_slug,
    l.name_ar AS location_name_ar,
    l.name_en AS location_name_en,
    l.country_code,
    l.country_ar,
    l.region_ar,
    l.climate,
    l.villa_count_estimate,
    l.permit_authority,
    p.slug AS pillar_slug,
    p.name_ar AS pillar_name_ar,
    cq.intent,
    cq.format,
    cq.target_keyword_ar,
    cq.priority_score
  FROM pseo.content_queue cq
  JOIN pseo.locations l ON cq.location_id = l.id
  JOIN pseo.pillars p ON cq.pillar_id = p.id
  WHERE cq.status = 'pending'
    AND l.is_active = true
    AND p.is_active = true
  ORDER BY cq.priority_score DESC, cq.created_at ASC
  LIMIT p_limit;
END;
$$ LANGUAGE plpgsql;
```

### Dynamic Route Handler

```typescript
// app/(pseo)/[...slug]/page.tsx
import { notFound } from 'next/navigation';
import { getPublishedPage } from '@/lib/pseo/queries';
import { PSELandingPage } from '@/components/pseo/PSELandingPage';

export const revalidate = 86400; // ISR: revalidate every 24 hours

interface PageProps {
  params: Promise<{ slug: string[] }>;
}

export default async function PSEOPage({ params }: PageProps) {
  const { slug } = await params;
  const urlPath = `/${slug.join('/')}/`;
  
  const page = await getPublishedPage(urlPath);
  if (!page) return notFound();
  
  return <PSELandingPage data={page} />;
}

export async function generateMetadata({ params }: PageProps) {
  const { slug } = await params;
  const urlPath = `/${slug.join('/')}/`;
  const page = await getPublishedPage(urlPath);
  
  if (!page) return {};
  
  return {
    title: page.title_ar,
    description: page.meta_description_ar,
    alternates: { canonical: `https://foldablegarage.wasleen.com${page.url_path}` },
    other: {
      'application/ld+json': JSON.stringify(page.schema_json),
    },
    openGraph: {
      title: page.title_ar,
      description: page.meta_description_ar,
      images: [{ url: '/og-image.jpg', width: 1200, height: 630 }],
    },
  };
}
```

## 🚨 QUALITY CONTROL SYSTEM

### 5 Critical Protections

#### 1. Thin Content Prevention
- **Rule**: Every page MUST reference at least 3 local data fields (climate, landmarks, architecture style, municipality, etc.)
- **Enforcement**: Automated quality scoring checks for location-specific mentions
- **Penalty**: Pages scoring < 70 are flagged for review, not published

#### 2. Duplication Prevention
- **Rule**: H2 headings must differ across pages in the same pillar
- **Enforcement**: Cosine similarity check against last 50 pages in same pillar
- **Penalty**: Duplicate score > 85% → page quarantined, regeneration triggered

#### 3. E-E-A-T Enforcement
- **Rule**: Every page must include technical specifications (not generic "high quality" claims)
- **Requirements**:
  - Specific aluminum gauge (e.g., 1.5mm, 2.0mm)
  - Specific coating type (e.g., PVDF polyester powder coating)
  - Specific polycarbonate thickness (e.g., 6mm, 8mm, 10mm)
  - Real local permit requirements
  - Friction details (realistic challenges, timelines)
- **Penalty**: Pages without technical specifics → quality score reduced by 20 points

#### 4. Keyword Cannibalization Prevention
- **Rule**: Strict intent mapping per template
- **URL uniqueness**: Composite unique index on (location_id, pillar_id, intent, format)
- **Title uniqueness**: Every title must be unique across all pages in the system

#### 5. Hallucination Prevention
- **Rule**: Strict bounds on generated numbers
- **Must flag [SOURCE: verify]**:
  - Exact pricing per square meter
  - Specific legal requirements or permit costs
  - Competitor claims
  - Statistical claims without named source
- **Safe to generate**:
  - Geography: city names, region names
  - Common knowledge about carports
  - Standard installation processes
  - Cultural and economic context from location_data

### Quality Scoring Formula

```typescript
function calculateQualityScore(content: any, wordCount: number): number {
  let score = 0;
  
  // Word count (0-25 points)
  if (wordCount >= 1500) score += 25;
  else if (wordCount >= 1000) score += 20;
  else if (wordCount >= 700) score += 15;
  else score += 5;
  
  // Location specificity (0-25 points)
  const locationMentions = countLocationMentions(content);
  if (locationMentions >= 5) score += 25;
  else if (locationMentions >= 3) score += 20;
  else score += locationMentions * 5;
  
  // Technical specificity (0-20 points)
  const techTerms = ['ملم', 'PVDF', 'بولي كربونيت', 'ألمنيوم', 'زجاج', 'مقاوم', 'عازل'];
  const techCount = countTermMentions(content, techTerms);
  score += Math.min(techCount * 4, 20);
  
  // FAQ count (0-10 points)
  const faqCount = content.faqs?.length || 0;
  if (faqCount >= 5) score += 10;
  else score += faqCount * 2;
  
  // CTA strength (0-10 points)
  if (content.cta_text?.length > 30) score += 10;
  else if (content.cta_text?.length > 15) score += 5;
  
  // Internal links (0-10 points)
  const linkCount = content.internal_links_used?.length || 0;
  score += Math.min(linkCount * 3, 10);
  
  // Schema presence (0-5 points)
  if (content.has_schema) score += 5;
  
  return Math.min(score, 100);
}
```

| Score | Grade | Action |
|-------|-------|--------|

| 75-89 | 🟡 Good | Publish, flag for weekly review |
| 60-74 | 🟠 Marginal | Regenerate with enhanced prompt |
