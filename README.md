# Wasleen Foldable Premium Garage

**Architectural-grade retractable carports for UAE villas.**

Built with Next.js 15 (App Router), Tailwind CSS v4, TypeScript, Supabase, Paddle, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

Copy `.env.local` template from `plans/credentials_and_config.md`.

## Deployment

Push to `main` → Vercel auto-deploys to `foldablegarage.wasleen.com`.
